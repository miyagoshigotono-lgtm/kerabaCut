# ケラバ図メーカー

ケラバ図（A4横）と 破風・鼻隠し発注書（A4縦）を作って PDF で出すアプリです。
ブラウザだけで動きます。

---

## 1. 最初の一回だけ：GitHub に置く

### ① リポジトリを作る

GitHub で新しいリポジトリを作ります（名前は `keraba` など）。

> **公開設定について**
> GitHub Pages は **無料プランだと Public のリポジトリでしか使えません**。
> Private のまま公開したい場合は GitHub Pro が必要です。
> このアプリに顧客情報は入っていません。参考図面の PDF は `.gitignore` で
> **除外済み**なので、リポジトリには上がりません。

### ② このフォルダを push する

```
git remote add origin https://github.com/<あなたのID>/keraba.git
git branch -M main
git push -u origin main
```

### ③ Pages を有効にする

リポジトリの **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に変更します。

これで数十秒後に次のURLで開けるようになります。

```
https://<あなたのID>.github.io/keraba/
```

---

## 2. ふだんの更新のしかた

**main にマージ（または push）するだけです。**

1. GitHub Actions が自動で走る
2. 日時＋コミットIDから新しいバージョン番号を作り、`index.html` `sw.js` `version.json` の
   3ファイルに同じ番号を刻む
3. `app` フォルダを Pages に配信

各パソコンのアプリは `version.json` を **起動時・3分ごと・ウィンドウを触ったとき** に見ていて、
番号が変わっていたら **自動で最新版を読み直します**（バナーが出て4秒後）。
手でバージョンを上げる必要はありません。

> 作業中に更新が来ても、入力内容は消えません（下記のとおり自動保存されています）。

---

## 3. 使う人の操作

- URL を開くだけで使えます
- アドレスバーの **インストール** を押すと、専用ウィンドウ＋デスクトップアイコンになります
  （中身は同じアプリです。自動更新もそのまま効きます）
- 一度開いておけば、ネットが切れていても起動します
- **入力内容はそのパソコンに自動保存**されます。閉じても次回は続きから。
  まっさらに戻すときは「既定値に戻す」を押してください
- 保存はパソコンごとなので、他の人の入力と混ざりません

---

## 4. ファイル構成

```
app/                     ← 配信されるのはこのフォルダだけ
  index.html             アプリ本体（1ファイル完結）
  sw.js                  オフライン動作・自動更新
  manifest.webmanifest   インストール用の定義
  version.json           更新検知に使う版番号
  icon-*.png             アイコン
  サーバー起動.bat        社内LANで配る場合のみ使用
.github/workflows/
  deploy.yml             main に入ると自動で配信
_バージョンを上げる.py     GitHubを使わずに配る場合の手動バージョン更新
```

---

## 5. GitHub を使わずに配る場合

| 方法 | 手順 | 注意 |
|---|---|---|
| ファイルサーバー | `app` フォルダを共有に置き、`index.html` を開く | `file://` だと入力内容を保存できないことがあります（赤いバーで警告が出ます） |
| 社内LAN配信 | 常時起動のPCで `app/サーバー起動.bat` を実行し、表示された `http://192.168.x.x:8080/` を全員が開く | HTTP なのでインストールとオフラインは使えません。自動更新は効きます |

どちらの場合も、アプリを直したあとに `_バージョンを上げる.py` を1回実行してから
`app` フォルダを上書きコピーしてください。
